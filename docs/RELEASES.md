# Release plan

No Shallette builds have been published. A badge-edition build (version 0.0.1, a repack of Zen 1.23.4b — see [`BADGE-EDITION.md`](BADGE-EDITION.md)) exists locally but is not distributed from this repository.

Before creating release variants, document for each one:

- variant name and purpose;
- source commit and upstream revision;
- build configuration and reproducible build command;
- supported operating systems and architectures;
- update channel and update endpoint ownership;
- signing and notarization status;
- included third-party notices and source offer or source publication location where required;
- artifact checksums and release notes.

Keep prerelease and stable artifacts clearly labeled. Do not distribute binaries derived from upstream source until license, trademark, and distribution requirements have been reviewed.
