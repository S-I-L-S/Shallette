# Shallette — цель проекта (GOAL.md)

## Видение
Бесплатный open-source браузер с единым брендом Shallette и узнаваемым UX на максимальном числе платформ. Не собственный движок. Не форк без бренда. Не свой сервер синхронизации.

## Движки
На одной ОС могут существовать несколько сборок Shallette с разными движками (например, Windows: Gecko + WebKit). База — Zen/Firefox (Gecko). Там, где Gecko недоступен — WebKit. Собственного движка не разрабатываем.

## Синхронизация
Используется синхронизация движка (Firefox Sync). Собственный сервер синхронизации не разрабатывается.

## Обновления
Свой update-сервер Shallette — открытый вопрос, требует решения до v1.

## Обязательное в v1 (must-have)
- Рендер современных сайтов
- Профиль, сессии, пароли (сохранение между запусками)
- Обновления (свой канал)
- Расширения (addons.mozilla.org или совместимые)
- Видео / DRM (Widevine / EME)
- Аппаратное ускорение (где движок позволяет)
- Подпись / нотаризация (Windows code signing, Android keystore; macOS — без подписи, обход Gatekeeper)
- Установщики и пакеты (EXE / MSI, APK, BSD ports / пакеты, пакет Haiku)
- Локализация (все языки базового движка + русский / украинский)

## Ограничения и риски
1. **«Всё сразу» с одним разработчиком + сетью ИИ-агентов** — амбициозно, может потребоваться phased rollout.
2. **BSD-порты зависят от upstream** — мы не портируем Firefox под каждую BSD сами, ждём официальный порт каждой системы.
3. **Apple без подписки** — iOS / iPadOS не входят в v1; macOS — только для энтузиастов с ручным обходом Gatekeeper.
4. **Haiku** — нет Firefox / Gecko, только WebKit (Tier 3).
5. **HarmonyOS** — нет порта Gecko; экспериментальный статус.

## Ресурсы
Пока один разработчик + сеть ИИ-агентов. Люди добавятся позже.
